# Learning outcomes and graduation path

This app is designed to be a private, standalone daily learning app for becoming comfortable with Python basics and general coding habits.

## End goal

By the end of the 30-day path, the learner should be able to:

- Read and write simple Python scripts.
- Use variables, strings, numbers, booleans, assignment, and comparison.
- Make decisions with `if`, `elif`, and `else`.
- Repeat work with loops.
- Write reusable functions with inputs and return values.
- Use lists and dictionaries to store multiple values.
- Debug common beginner errors by reading messages and isolating one failing line.
- Write simple tests or manual checks for expected behavior.
- Understand basic file, JSON, API, and object-oriented vocabulary.
- Use AI as a learning partner for hints, checks, explanations, and project planning without copying blindly.
- Build and explain a small beginner project or capstone feature.

## Milestones

The app's Path tab now turns the 30-day plan into six milestone checkpoints.

1. **Python starting line**: print, variables, types, basic conditions, and error confidence.
2. **Control flow and functions**: if statements, loops, functions, and return values.
3. **Data, debugging, and tests**: lists, dictionaries, error reading, and asserts.
4. **Real-world Python shapes**: files, JSON/API concepts, and simple object thinking.
5. **AI-assisted coding habits**: better prompts, hints-first AI help, mini-project planning.
6. **Capstone graduation**: a tiny project or app feature with a demo note and QA checklist.

## Graduation requirements

The app considers the learner ready to graduate when the evidence shows:

- Core Python lessons are completed.
- Daily coding-gym sessions are completed across the plan.
- Proof cards are saved.
- Lesson quizzes are passed.
- Project checkpoints are completed.
- Mistake/review cards are logged.
- Strong AI prompts are practiced.

The goal is not just to click through lessons. The goal is to collect proof that the learner can explain, practice, debug, and build.

## Daily flow

The recommended daily flow is still:

```text
Open app -> press Start Today -> finish one workout block at a time -> save proof -> stop
```

A 10-minute rescue day still counts as habit protection. A 30-minute day is the default. A 45-minute day is for deeper project energy.
