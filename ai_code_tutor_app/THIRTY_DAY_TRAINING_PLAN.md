# 30-Day Coding Training Plan

This app is now built around a simple beginner-friendly habit: **30 minutes a day for 30 days**. Each day has four short blocks so a new learner can make progress without burning out.

## Daily rhythm

Most days follow this structure:

1. **Warm up - 5 minutes**: recall yesterday's idea before reading notes.
2. **Learn - 10 minutes**: read a lesson or inspect an example.
3. **Practice - 10 minutes**: code, modify, debug, or test something tiny.
4. **Reflect - 5 minutes**: save one note, one question, and one win.

Build days swap the learning block for a tiny project sprint. Review days use active recall, repair, practice, and reflection.

## What the learner finishes with

By day 30, the learner should have:

- touched every Python lesson in the app;
- practiced variables, conditionals, loops, functions, data structures, files/JSON/APIs, debugging, tests, OOP, prompting, mini-projects, and Streamlit basics;
- used review days to revisit older concepts;
- built or planned a tiny capstone app;
- practiced asking AI for hints, examples, tests, and explanations;
- queued at least one official AI learning resource such as Gumloop or Anthropic Academy.

## Full plan

The source of truth is `study_plan.py`, which keeps each day machine-readable for the app and tests. In the app, open the **Today** tab to see the next mission, review queue, AI side quest, and badge shelf.
